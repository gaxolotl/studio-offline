# notes/ — index

RE and design notes for the Studio-Offline fork. Read `AGENTS.md` first.

- **offsets-scanner.md** — how `offsets_scanner` works: PE reconstruction,
  URL scanning rules (boundary union rule, denylist, replacement), hand-written
  patterns, generic trust-check detection, security cookie, offsets.json
  consumption by the DLL. The main doc for the scanner.
- **server-architecture.md** — the axum server: modes (Asset Grab / Regular /
  Reflection), routes (assets, uploads, datastores, avatar, OAuth, telemetry),
  file layout, deploy.
- **RE-latest-place-version.md** — original reverse-engineering of the
  "Error fetching latest place version" bug (place 95206881) that led to the
  `FETCHER_JNE_THROW` NOP + `Data/Upload.ashx` redirect.
- **datastore_test.luau** — Studio-side test script for the local file-backed
  datastores.
- **disasm.py / xrefs.py** — capstone helpers for inspecting
  `RobloxStudioBeta.exe`. Need `pip install capstone` and `STUDIO_EXE` env var
  on a new PC (see RE-latest-place-version.md).

## Historical context

This branch (`re-latest-place-version`) is a fork of
https://github.com/Roblox-Devs/studio-offline (upstream). It adds, beyond the
original AOB-scanning DLL:
1. Data-driven patching via `offsets.json` generated by the scanner.
2. Generic (string-anchored) trust-check gate detection.
3. Fixes for "latest place version", AsyncHttpQueue trust check, security
   cookie, and asset/URL coverage across Roblox builds.
4. Avatar customization + file-backed datastores in the server.
